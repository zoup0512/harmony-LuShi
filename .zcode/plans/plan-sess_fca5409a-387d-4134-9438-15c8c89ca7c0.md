## 美术升级实施方案

### 目标
在不修改玩法规则、数值和页面流程的前提下，把当前“纯色块 + emoji”界面升级为统一的原创暗色奇幻酒馆风。优先采用 API 12 稳定支持的本地 PNG/WebP 与标准 ArkUI `Image`，保留文字信息和资源缺失时的降级显示。

### 1. 建立美术资源与映射层
- 在 `entry/src/main/resources/base/media/` 增加一套原创、非炉石版权复刻的本地素材：
  - 主菜单酒馆背景、对局桌面背景、战斗竞技场背景、胜利/失败装饰背景。
  - 6 位英雄的小尺寸肖像。
  - 8 个种族的通用随从插画/徽记，确保现有全部随从都有视觉素材；不一次性引入几十张高分辨率单卡图，控制包体和内存。
  - 金币、攻击、生命、酒馆等级及刷新/升级/冻结/技能/战斗等轻量图标。
  - 嘲讽、圣盾、剧毒、风怒、复生、亡语、顺劈等关键词图标。
- 新增 UI 专用 `ArtAssets.ets` 资源解析器，按英雄 ID、随从种族、关键词和操作类型返回 `$r('app.media.*')`。
- 资源映射留在 UI 层，不给 `HeroDef`/`MinionDef` 塞 HarmonyOS `Resource`，避免游戏数据层依赖 ArkUI；保留 emoji/文字作为兜底。

### 2. 扩展视觉主题
- 扩充 `ui/Theme.ets`：增加半透明面板色、遮罩色、选中/受击/冻结状态色、阴影与动画时长常量。
- 继续使用现有种族色作为插画蒙层、边框和状态识别色，使新素材与旧信息层保持一致。
- 不依赖尚未验证的原生渐变或 `SymbolGlyph`；需要渐变质感时使用图片素材或多层半透明 `Stack` 实现，保证 API 12 兼容。

### 3. 升级核心卡牌组件
- 重构 `MinionCard.ets` 的中部区域：加入种族插画，叠加暗色文字遮罩，再显示名称和种族，保留当前卡片尺寸及所有点击逻辑。
- 攻击/生命由纯色数字块升级为带图标的徽章；商店价格使用金币图标替代 emoji。
- 关键词由单字色块升级为图标徽章，仍保留短文字以保证小屏可读性。
- 强化金卡、选中、受伤、不可购买状态：金色覆盖层、描边/阴影、高亮与暗化，但不改变 `selected/clickable/dimmed` 的语义。
- 所有商店、手牌、战场和战斗回放自动复用这次升级。

### 4. 升级英雄与页面场景
- `HeroPanel.ets`：用英雄肖像替代主视觉 emoji，保留圆形金边和敌方标记；血条、金币、酒馆等级加入图标和更清晰的层次。
- `MainMenuPage.ets`：改为背景图 + 深色可读性遮罩；英雄选择卡使用肖像和选中光效；详情面板加入大头像与技能装饰；标题和开始按钮改为原创酒馆风视觉。
- `GamePage.ets`：加入桌面背景与半透明分区面板；顶部回合/金币、选中操作条和 Toast 统一视觉；冻结状态传给商店以显示冰蓝遮罩和“已冻结”标识。
- `BoardRow.ets`、`HandRow.ets`、`ShopRow.ets`：增加战场槽位、手牌托盘和商店货架的容器质感，保持现有尺寸和滚动/点击行为。
- `ActionButton.ets`：增加图标参数，形成“图标 + 主文字 + 花费/状态”结构；保留禁用态和原有回调。
- `ResultPage.ets`：增加胜利/失败场景背景和徽章，升级战绩卡及按钮，不改变清理 Session 和返回菜单的导航逻辑。

### 5. 增强战斗反馈
- `BattleReplay.ets` 使用现有事件流与 `highlightUid/flashing/floatText`，补上目前未渲染的攻击者高亮。
- 为攻击、伤害、圣盾、召唤、复生和死亡加入短促的缩放/透明度/位移反馈；动画时长控制在现有 650ms 事件间隔内，避免改变回放节奏。
- 浮字按事件类型使用红/金/绿/紫等颜色，战斗结束展示更醒目的结果横幅。
- 保留现有定时器、事件应用和 `onFinish` 时序，不修改战斗模拟器。

### 6. 兼容性与验证
- 首先执行 `node hvigorw.js assembleHap --no-daemon`，修复全部 ArkTS 类型、资源名和 API 12 兼容问题。
- 确认生成 `entry/build/default/outputs/default/entry-default-unsigned.hap`，并检查新资源已进入 HAP。
- 若本机可用 HarmonyOS 模拟器/预览器，则运行检查主菜单、英雄选择、购买/出牌、冻结、战斗回放、胜负页和小屏布局；若不可用，会明确说明只完成了编译验证。
- 不引入第三方依赖，不修改 `GameEngine`、`BattleSimulator`、AI 或数值数据。

### 预计主要改动文件
- 新增：`entry/src/main/ets/ui/ArtAssets.ets`
- 新增：`entry/src/main/resources/base/media/` 下的背景、肖像、种族和界面图标素材
- 修改：`ui/Theme.ets`
- 修改：`ui/components/MinionCard.ets`、`HeroPanel.ets`、`ActionButton.ets`、`BoardRow.ets`、`HandRow.ets`、`ShopRow.ets`、`BattleReplay.ets`
- 修改：`pages/MainMenuPage.ets`、`GamePage.ets`、`ResultPage.ets`
